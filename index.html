FAQ

Apakah benar-benar tanpa limit harian?

Ada fair-use cap (120 req/menit, 100rb token/menit) biar satu user nggak makan semua resource. Buat pemakaian manusia normal — coding, chat, agent — cap ini nggak bakal kerasa.

Modelnya disensor atau tidak?

Uncensored. Ini varian Turbo yang memang dirilis tanpa alignment filter bawaan.

Bisa dipakai untuk apa saja?

Apa aja yang support format OpenAI: aplikasi chat, coding assistant, agent dengan function calling, automation, riset. Base URL-nya https://ai.nandzstore.com/v1.

Bagaimana kalau API-nya down?

Garansi refund 100% untuk masa aktif yang terganggu. Status operasional bisa dicek kapan aja — kalau kami nggak bisa kasih layanan, kamu nggak bayar.

Apakah chat saya disimpan?

Tidak. Kami cuma catat usage (jumlah request/token), error rate, dan latency per key buat monitoring. Isi prompt dan response nggak pernah disimpan.
